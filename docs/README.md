## Quick orientation

**New to the project?** Start with [ARCHITECTURE.md](ARCHITECTURE.md) for a system overview, then [GETTING_STARTED.md](GETTING_STARTED.md) to run it locally.

**Working on the iOS app?** See [IOS_APP.md](IOS_APP.md) for component details. **Shipping a build to testers?** See [TESTFLIGHT.md](TESTFLIGHT.md).

**Working on the backend?** See [API_REFERENCE.md](API_REFERENCE.md) and [DATA_MODEL.md](DATA_MODEL.md).

**Running or improving the ML model?** See [ML_PIPELINE.md](ML_PIPELINE.md).

**Deploying to production?** See [DEPLOYMENT.md](DEPLOYMENT.md) and [SECURITY.md](SECURITY.md).

**Deciding what to build next?** See [MOSCOW.md](MOSCOW.md).
