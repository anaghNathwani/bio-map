# Awesome-list pull requests

**Why it helps:** Curated GitHub lists (citizen science, bioacoustics, on-device ML) send steady, relevant traffic.

**Who does it:** you (needs your account or your judgement; it can't be done from the repo).

## Steps

1. Most lists only accept public repositories, so decide on playbook 79 first.
2. Search GitHub for `awesome citizen science`, `awesome bioacoustics`, `awesome tflite`; read each list's contribution rules.
3. Open one PR per list with a one-line entry in the required format.

**Done when:** you've opened PRs or decided none fit.
