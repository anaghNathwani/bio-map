# Request indexing for each important URL

**Why it helps:** A brand-new site can wait weeks to be crawled. Manually requesting indexing for key pages usually speeds up the first visit.

**Who does it:** you (needs your account or your judgement; it can't be done from the repo).

## Steps

1. Search Console → paste a URL into the **URL inspection** bar at the top.
2. If it says *URL is not on Google*, click **Request indexing**. Repeat for the pages below, most important first (there is a daily quota; do a few a day).
3. Don't resubmit pages that are already indexed.

**Done when:** the home page, /map, /how-it-works, /bird-sound-identification and /bird-photo-identification show as indexed.
