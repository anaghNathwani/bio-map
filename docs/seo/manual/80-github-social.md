# GitHub social preview image

**Why it helps:** Controls the card shown when the repo is shared.

**Who does it:** you (needs your account or your judgement; it can't be done from the repo).

## Steps

1. Repo → **Settings** → **Social preview** → upload `web/public/og-image.png` (1200x630).

**Done when:** the preview appears in the settings page. Only useful if the repo is public.
