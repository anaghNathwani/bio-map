# Website SEO

How the marketing site (`web/`) is set up to be found on Google, and what you still have to do yourself.
The 100-step checklist is in [SEO_PLAN.md](SEO_PLAN.md); manual steps have playbooks in [seo/manual/](seo/manual/).

Live site: https://birdmap-citizenscience.web.app (free Firebase Hosting subdomain).
No one can promise a ranking. This makes the site crawlable, fast, well described and linked to.

## How it works

| Piece | Where |
|---|---|
| Per-page title, description, canonical, robots, Open Graph, JSON-LD | `web/src/site.js` (route registry) |
| Client-side updates on navigation | `web/src/lib/pageMeta.js` (`usePageMeta`) |
| Real HTML for every page (prerender) | `web/src/entry-server.jsx`, `web/scripts/prerender.mjs` |
| Sitemap, RSS, security.txt | generated by `prerender.mjs` from the registry |
| Lint of the built site | `web/scripts/seo-check.mjs` (`npm run seo:check`) |
| Hosting config (clean URLs, 404, cache and security headers) | `web/firebase.json` |
| IndexNow (Bing/Yandex) | `web/scripts/indexnow.mjs` |

`npm run build` = client build, SSR build, then prerender, so `dist/ai.html`, `dist/blog/....html` etc. contain
real content. Only the interactive map (`/map`) is a client-rendered shell (with its own title/description/JSON-LD).

## Adding a page

1. Add an entry to `ROUTES` in `web/src/site.js` (path, unique title 10-65 chars, description 70-170 chars, `prerender: true`).
2. Add the page component and its `<Route>` in `web/src/routes.jsx` (use `ContentPage` for text pages).
3. For a blog post, add it to `web/src/content/posts.js` instead; the route, JSON-LD, sitemap and RSS entry follow.
4. `npm run build && npm run seo:check`.

## Things left blank on purpose (set them when you have them)

- `CONTACT_EMAIL` in `web/src/site.js`: shows a contact line on the privacy page and generates `/.well-known/security.txt`.
- `SOCIAL_PROFILES` in `web/src/site.js`: shows profile links in the footer and adds Organization `sameAs`.
- `GOOGLE_SITE_VERIFICATION` in `web/src/site.js`: paste the token Search Console gives you (see the playbook).

## Deploying

```bash
cd web && npm run build && npm run seo:check && firebase deploy --only hosting
```
or run the "Deploy web to Firebase Hosting" GitHub Action (needs the `FIREBASE_SERVICE_ACCOUNT_JSON` secret).
